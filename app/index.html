      What to do now

      This is a helper, not a guarantee. Scammers change their words. When in doubt, call the company or person using a number you already know — never a number from the message.

      How it works

      SafeText uses a machine-learning model (TF-IDF + logistic regression) trained on 24,161 real and published example messages — the UCI SMS Spam Collection (Almeida et al., 2011) and the Scam Shield SMS dataset (Hugging Face, CC-BY-4.0). The model learned which words and phrases appear in scams, and it shows you exactly which words pushed the score up.

      • Held-out test (4,833 messages it never saw while training): accuracy 93.3%, precision 94.4%, recall 92.2%.
      • Independent check (1,510 more messages, never trained on): accuracy 95.2%, precision 99.2%, recall 93.9%.
      • What it is bad at: scams that read like an ordinary family message are the hardest — it caught 6 out of 6 of our demo examples, but a brand-new scam wording can still slip through. It only works in English.
      • Privacy: the trained model is a file shipped with this page. Your message never goes to a server.

      Datasets: UCI Machine Learning Repository, “SMS Spam Collection” (DOI 10.24432/C5CC84); Hugging Face, “rasheq/scam-shield-sms” (CC-BY-4.0). Built for SLAY HACKS 2026.
